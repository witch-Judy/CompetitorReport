# Insight 目录

本目录包含经过深入分析的关键洞察和发现。

## 目录结构

```
insight/
├── README.md                    # 本文件
├── reports/                     # 分析报告
│   ├── Siemens_Webinar深度分析报告_LLM增强.md
│   ├── 综合内容类型统计表.md
│   ├── 参考公司综合内容类型统计表.md
│   └── 跨行业分析价值评估报告.md
└── data/                        # 原始数据文件
    ├── 综合内容类型统计表.csv
    ├── 参考公司综合内容类型统计表.csv
    ├── 跨行业内容策略对比表.csv
    └── unknown_webinar_reclassified.json
```

## 使用说明

### Reports（报告）

`reports/` 目录包含所有分析报告，以Markdown格式保存：

- **Siemens_Webinar深度分析报告_LLM增强.md** - Siemens Webinar的深度分析，使用LLM增强分类
- **综合内容类型统计表.md** - 所有竞品公司的内容类型统计和分析
- **参考公司综合内容类型统计表.md** - 参考公司（跨行业）的内容类型统计
- **跨行业分析价值评估报告.md** - 跨To C/To B、跨行业分析的价值评估

### Data（数据）

`data/` 目录包含所有原始数据文件，用于进一步分析和可视化：

- **综合内容类型统计表.csv** - 竞品公司内容类型统计数据
- **参考公司综合内容类型统计表.csv** - 参考公司内容类型统计数据
- **跨行业内容策略对比表.csv** - 跨行业对比数据
- **unknown_webinar_reclassified.json** - Webinar重新分类的详细数据

## 重要说明

⚠️ **只有用户明确要求放入insight目录的分析结果才会放在这里**

这些文件都是经过深入分析和验证的关键洞察，可以直接用于：
