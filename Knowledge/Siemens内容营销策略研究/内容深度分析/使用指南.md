# Siemens 内容深度分析使用指南

## 🎯 目标

深入分析Siemens的每一篇内容，了解：
1. **内容架构** - 如何组织内容（标题、段落、格式等）
2. **写作原因** - 为什么这样写（SEO、用户体验、营销目标等）
3. **内容模式** - 总结架构和原因，形成可参考的模式

## 📋 完整工作流程

### 阶段1: 深度内容分析

#### 1.1 分析Blog内容（推荐先做，内容相对简单）

```bash
# 分析20个blog样本
python3 analysis/siemens_content_deep_analyzer.py --content-type blog --limit 20
```

**输出**:
- `blog_内容架构与原因分析.md` - 详细分析报告
- `blog_analysis_data.json` - 完整分析数据
- `原始内容/{url_hash}.json` - 每个URL的原始内容

#### 1.2 分析Webinar内容

```bash
# 分析20个webinar样本
python3 analysis/siemens_content_deep_analyzer.py --content-type webinar --limit 20
```

#### 1.3 分析Industry内容

```bash
# 分析20个industry样本
python3 analysis/siemens_content_deep_analyzer.py --content-type industry --limit 20
```

#### 1.4 分析Customer Story内容

```bash
# 分析所有customer story（数量较少）
python3 analysis/siemens_content_deep_analyzer.py --content-type customer_story --limit 27
```

#### 1.5 分析指定URL

```bash
# 分析特定URL
python3 analysis/siemens_content_deep_analyzer.py --urls "https://..." "https://..."
```

---

### 阶段2: 总结内容模式

#### 2.1 总结特定内容类型的模式

```bash
# 总结blog内容模式
python3 analysis/siemens_content_pattern_summarizer.py --content-type blog

# 总结webinar内容模式
python3 analysis/siemens_content_pattern_summarizer.py --content-type webinar
```

**输出**: `写作模式/{content_type}_内容模式总结.md`

#### 2.2 生成综合模式总结

```bash
# 总结所有内容类型的模式
python3 analysis/siemens_content_pattern_summarizer.py
```

**输出**: `写作模式/内容模式总结.md`

## 📊 分析维度

### 内容架构分析

1. **标题结构**
   - 格式类型（dash_separated, pipe_separated等）
   - 标题长度
   - 分隔符使用

2. **标题层级**
   - H1-H6的使用情况
   - 最大深度
   - 层级分布

3. **内容组织**
   - 段落数量
   - 平均段落长度
   - 总字数
   - 内容长度分类（短/中/长）

4. **格式化元素**
   - 列表使用
   - 图片使用
   - 链接使用

### 写作原因分析

1. **SEO优化**
   - Meta描述
   - Meta关键词
   - 结构化数据（JSON-LD）
   - 标题优化
   - 图片Alt标签

2. **用户体验**
   - 可读性得分
   - 可扫描性
   - 参与元素（图片、列表、链接）

3. **营销目标**
   - 内容深度（浅/中/深）
   - CTA（行动号召）使用
   - 转化元素（表单、下载等）

4. **内容策略**
   - 内容类型推断
   - 目标受众
   - 内容目的（教育/转化/意识）

## 💡 使用建议

### 建议1: 循序渐进

1. **先分析少量样本**（5-10个）测试系统
2. **确认内容提取正常**后，增加样本数量
3. **针对不同内容类型**分别分析
4. **总结模式**，形成可参考的架构和原因

### 建议2: 重点关注

- **Blog**: 内容相对简单，适合理解基本架构
- **Webinar**: 可能有注册表单等转化元素
- **Industry**: 行业解决方案，可能有深度内容
- **Customer Story**: 案例研究，可能有特定结构

### 建议3: 批量分析

可以创建一个批量分析脚本，一次性分析多个内容类型：

```bash
# 分析多个类型
for type in blog webinar industry customer_story; do
    python3 analysis/siemens_content_deep_analyzer.py --content-type $type --limit 20
    python3 analysis/siemens_content_pattern_summarizer.py --content-type $type
done
```

---

## ⚠️ 注意事项

1. **爬取限制**: 默认2秒延迟，避免对服务器造成压力
2. **内容提取**: 某些页面可能需要JavaScript渲染，可能无法完全提取
3. **数据量**: 建议使用`--limit`限制分析数量
4. **网络**: 需要稳定的网络连接
5. **时间**: 大量URL分析需要较长时间
