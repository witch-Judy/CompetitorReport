# 内容营销数据库分析指南

## 📊 两种分析视角

### 视角1: 按公司分析（纵向）- 深度研究

**适用场景**:
- ✅ 深度研究特定公司的完整内容策略
- ✅ 了解公司的内容分类体系
- ✅ 分析公司的内容发布节奏和趋势
- ✅ 研究公司的整体内容架构

**使用方法**:
```bash
# 分析单个公司
python3 analysis/content_comparison_analyzer.py --mode company --company cognite

# 分析所有公司
python3 analysis/content_comparison_analyzer.py --mode company
```

**生成报告**: `{company}_内容策略分析.md`

**报告内容**:
- 总体概览（总内容数、内容类型数）
- 内容类型分布
- 内容分类体系
- URL命名模式
- URL结构分析
- 内容发布时间线

---

### 视角2: 按内容类型对比（横向）- 学习最佳实践

**适用场景**:
- ✅ 学习特定内容类型的创作方法
- ✅ 横向对比不同公司的同类内容策略
- ✅ 发现行业最佳实践和模式
- ✅ 寻找内容创作灵感和参考

**使用方法**:
```bash
# 对比whitepaper
python3 analysis/content_comparison_analyzer.py --mode type --content-type whitepaper

# 对比case_study
python3 analysis/content_comparison_analyzer.py --mode type --content-type case_study

# 为主要内容类型生成对比报告
python3 analysis/content_comparison_analyzer.py --mode type
```

**生成报告**: `{content_type}_横向对比分析.md`

**报告内容**:
- 各公司内容数量对比
- 分类模式对比
- 命名模式对比
- URL模式示例
- 最佳实践总结

## 📋 工作流程建议

### 阶段1: 快速了解（综合视角）
```bash
python3 analysis/content_comparison_analyzer.py --mode comprehensive
```
→ 了解整体情况，确定研究方向

### 阶段2: 深度研究（按公司）
```bash
# 选择1-2个重点公司深度研究
python3 analysis/content_comparison_analyzer.py --mode company --company cognite
python3 analysis/content_comparison_analyzer.py --mode company --company aveva
```
→ 了解这些公司的完整策略

### 阶段3: 横向学习（按内容类型）
```bash
# 针对你关心的内容类型进行横向对比
python3 analysis/content_comparison_analyzer.py --mode type --content-type whitepaper
python3 analysis/content_comparison_analyzer.py --mode type --content-type case_study
```
→ 学习最佳实践，找到创作灵感

### 阶段4: 应用实践
- 参考最佳实践设计自己的内容策略
- 借鉴优秀的分类体系
- 学习有效的命名模式

## ❓ 常见问题

**Q: 我应该先看哪个视角？**
A: 建议先看综合报告，了解整体情况，然后根据你的具体需求选择纵向或横向分析。

**Q: 两种视角可以结合使用吗？**
A: 当然可以！先横向对比找到最佳实践，再纵向深度研究做得最好的公司。

**Q: 如何找到特定内容类型的创作灵感？**
A: 使用横向对比，查看不同公司如何处理同类内容，学习他们的分类、命名和结构方式。
